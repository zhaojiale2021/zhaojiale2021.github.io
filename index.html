深度参与过奇瑞、赛力斯、岚图、北汽、江淮等主机厂量产项目，熟悉 CAN/CANFD、部分 Ethernet、DoIP/DoCAN 诊断路由、SOME/IP、Bus Mirror、E2E 校验、网络管理等车载通信链路。

日常会用 Python 和 AI 工具沉淀自动化脚本、知识库与 Agent 记忆，持续提升配置生成、问题定位和跨项目交付效率。
